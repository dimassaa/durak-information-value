This number is a measurement, not a property of information

It is the delta at one search depth, one evaluation-weight vector, one reading of the throw-in rule, and one distribution of dealt trumps. The project's own depth curve moves it by more than the width of this interval, and the throw-in rule reading alone moves the win rate by 7.9 points. Treat it as one cell of a range. An earlier headline of +0.0799 was withdrawn: it was measured on a dataset that predates both the leaf fix and the deck-hiding change, and it did not reproduce with the code that replaced it.

This is a lower bound

This is a lower bound on the price of perfect knowledge, not an estimate of it. The informed search is depth-limited and evaluates positions one ply ahead, so it does not exploit everything it learns. A stronger player with the same information would convert more of it into wins.
